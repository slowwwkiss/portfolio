# Reza Baehaqiii — Portfolio

One page portfolio for **Achmad Reza Baehaqiii**, a builder from Bogor, Indonesia
who ships software fast with a team of AI agents.

Built for [One Who Codes 2026](https://isonewho.codes/) — a portfolio challenge
judging creativity, craft, content, and performance.

## What is inside

- `index.html` — hero, about, 7 projects, skills, contact
- `style.css` — dark theme, responsive, accessible
- `script.js` — a playable mini chess board in the hero, plus scroll reveal

No framework, no images, no webfonts, no tracking. Total weight about 25 KB.

## Run locally

```sh
python3 -m http.server
```

Then open http://localhost:8000/
